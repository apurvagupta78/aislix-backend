# Competitive Benchmark

**Research date:** 2026-09-11 (partial web verification)  
**Status:** Public positioning only — vendor-claimed metrics labeled as such. Pricing largely undisclosed.

**Aislix differentiation (implement, do not merely claim):**

- Faster first useful result with minimal setup  
- Clear scope, uncertainty, and evidence per capture  
- Useful deduplicated actions, not duplicate dashboard cards  
- Inspectable financial models and honest unavailable states  
- Lower measured cost per **usable** audit  

Mobile photo capture is **not** unique — win on trust, actionability, and ROI proof.

## Beachhead recommendation

**CPG brands, distributors, merchandising teams** auditing fragmented retail with existing smartphones — point-in-time observation, not continuous camera/robot monitoring initially.
